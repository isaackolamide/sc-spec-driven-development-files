# Technology Stack Spec: AgentClinic

## Language & Runtime

- **TypeScript**: Strict type safety enabled to prevent runtime errors and ensure compile-time correctness.
- **Node.js**: The server-side environment for hosting the AgentClinic backend APIs and services.

## Database & Storage

- **SQLite**: A lightweight, self-contained, and performant SQL database engine.
- **ORM / Query Builder**: A TypeScript-friendly library (such as Prisma or Drizzle ORM) to interact with the SQLite database with strong type safety.

## Frontend

- **HTML5 & Vanilla CSS**: Clean, semantic markup and custom modern CSS for rich aesthetics, dark mode, smooth animations, and premium styling.
- **React (Vite / Next.js)**: Component-based architecture for dynamic, interactive, and responsive dashboards for agents and clinic staff.
